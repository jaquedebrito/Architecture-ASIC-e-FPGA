# 💡 ASIC vs FPGA Design – Course Overview

## 🎯 Objectives

This course aims to provide a clear understanding of the differences between **Application-Specific Integrated Circuits (ASICs)** and **Field-Programmable Gate Arrays (FPGAs)**. Students will explore the development flows for both technologies and learn how to choose the most suitable option based on architectural needs and design requirements.

## 📚 Topics Covered

- Introduction to FPGAs and digital design concepts
- FPGA architecture and main vendors
- Basics of logic design for FPGAs
- Comparison between FPGA and ASIC development flows
- Practical design activity using FPGAs

## 🛠️ Outcome

By the end of the course, students will be able to:
- Understand when to use ASICs vs FPGAs
- Develop and simulate basic FPGA-based systems
- Navigate the design-to-implementation process for programmable hardware
